# AI Testing Playground

A demo project exploring how to apply QA automation to AI models.

## Features
- Pytest scripts for Hugging Face sentiment analysis
- Automated validation of AI model outputs
- Demonstrates QA principles applied to AI systems

## How to Run

### Local (CMD/Terminal)
1. Clone the repo:
   git clone https://github.com/Veri-ai/ai-testing-playground.git
   cd ai-testing-playground

2. Install dependencies:
   pip install -r requirements.txt

3. Run tests:
   pytest -v

### Online (No Local Setup)
- **GitHub Codespaces**: Open the repo in Codespaces and run the same commands above.
- **Replit**: Copy files into [Replit](https://replit.com/) and run directly in the browser.
